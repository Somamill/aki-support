# aki. support

Select **Scan Mac** and choose a folder. aki. shows files in that folder that use at least 100 MB of disk space. Use the folder icon or press Command-O to scan a different folder.

Select the files you want to move and confirm **Move to Trash**. Open Trash in Finder to check or restore files. Disk space is freed when you empty Trash.

If a scan returns no results, try a folder that contains larger files. Some files may be unavailable to aki., and long scans can return partial results. If a file changed since the scan, aki. skips it. Scan again to review the current file.

To get help, [open a support issue](https://github.com/Somamill/aki-support/issues/new). Include your macOS version, aki. version, and what you did. Use a sample folder if possible and remove private filenames from any screenshots. [Privacy policy](https://github.com/Somamill/aki-support/blob/main/PRIVACY.md)
